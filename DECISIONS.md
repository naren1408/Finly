# Finly decisions

I built Finly as a single-page Vite app with React and custom CSS to keep the code lightweight, easy to explain, and straightforward to deploy. The design system uses warm neutrals, one primary green accent, and one warm highlight accent so the page feels premium without becoming noisy.

The biggest time-conscious trade-off was using art-directed CSS and SVG visuals instead of sourcing and optimizing a full photography set. That kept the project self-contained, fast to ship, and safe to deploy without third-party asset risk while still supporting the warmer visual direction.

AI was used to help structure the implementation and draft supporting copy, but the final layout, data mapping, component composition, and design choices were curated and assembled for this specific project brief.
